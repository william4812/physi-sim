# physi-sim — HPC Thermal Solver

C++20 / Fortran 90 / CUDA 13.2 hybrid engine for 2D steady-state heat transfer.
GTX 1650 (sm_75, 16 SMs) · TDD · CI/CD · CMakePresets

Implements a modular `ISolver` interface with FSM-managed lifecycle, concurrent
dispatch, and a Fortran physics kernel pipeline. GPU acceleration via CUDA Jacobi
with per-step residual history and ProfilingHarness benchmarking.

## 4. Algorithm comparison — Jacobi vs TDMA
Comparing iterative vs. deterministic approaches on a 100x100 grid. The TDMA solver consistently converges with 3.69× fewer iterations compared to the Jacobi method.

## 5. GPU profiling — JacobiCPU vs JacobiGPU
Benchmarking is executed across multiple grid resolutions (e.g., 50x50, 100x100, 200x200) to a strict tolerance of `1e-7`, configured via `benchmark_config.json`. Performance benchmarks highlight the overhead of PCIe transfers versus VRAM residency.

![Wall Time Analysis](docs/figures/wall_time.png)
![Wall Time Residency Impact](docs/figures/wall_time_residency.png)

## 6. Phase 4: VRAM Residency Verification
This phase validates the VRAM-resident buffer implementation. By pinning data to the GPU and eliminating unnecessary PCIe transfers, we achieve performance gains while maintaining numerical parity with CPU-based solvers. The plots below confirm the consistency of the thermal field across all solver variants at the 100x100 comparison grid scale.

![Thermal Field Consistency Compare](docs/figures/thermal_compare_100.png)
